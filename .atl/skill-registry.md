## Compact Rules

### Project: options-quant

**Stack**: Java 25 + Spring Boot 4 backend · React 19 + Vite 6 frontend · IBKR TWS API

**Key constraints**:
- NEVER build after changes (`./gradlew build` is expensive and not required for dev)
- NEVER add "Co-Authored-By" to commits
- Backend runs on port 9090; frontend dev server on separate port via Vite proxy
- `legacy-reference/` package is EXCLUDED from compilation — preserved for reference only, do not edit or import from it
- All controller endpoints under `/live-ui` and `/backtest-ui` prefix
- Java records used for immutable DTOs (Signal, ScanActivity, TradePlan, etc.)
- `CopyOnWriteArrayList` + `ConcurrentHashMap` + `AtomicBoolean/Reference` for thread-safe live state
- Frontend state is polled (500ms–1s intervals), not WebSocket-pushed
- LocalStorage keys prefixed with `live_` for live dashboard persistence

**Testing**:
- Test command: `./gradlew test`
- Unit: JUnit 5 + AssertJ (src/test/java — strategy/, domain/, service/ packages)
- E2E: Playwright via `BasePlaywrightTest` (spins up real Spring Boot app on random port)
- Coverage: JaCoCo (`./gradlew jacocoTestReport`)
- No frontend test framework (Vite only, no vitest/jest)
- E2E tests require app on localhost — always extend `BasePlaywrightTest`
